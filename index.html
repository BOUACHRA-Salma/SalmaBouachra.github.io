Selected Projects

Job Market Clustering & Recommender

An end-to-end data pipeline that analyzes job market trends and map user skills to targeted career paths. The system engineers numerical vectors from raw job requirements to dynamically segment professional domains and predict optimal career matches.

K-Means Clustering TF-IDF Vectorization Pandas & NumPy Scikit-Learn Matplotlib & Seaborn

🔑 Pipeline Architecture:

  • Data Preprocessing: Engineered feature scaling pipelines to parse salary strings into average annual compensation; normalized geographical and role categorical text.
  • Feature Engineering: Transformed unstructured requirements into sparse multidimensional matrices using custom token filters; integrated binary indicators for workplace flexibility.
  • Algorithmic Segmentation: Optimized an unsupervised K-Means model to cluster multi-dimensional skill signatures into distinct market segments.
  • Inference Engine: Classifies user skill matrices into localized clusters to filter and recommend the top 10 trending jobs within that target ecosystem.

Sign Language Translation System

Developed a real-time computer vision application designed to interpret and translate sign language gestures into text. The system leverages a hybrid approach combining lightweight spatial landmark tracking with custom Deep Learning classification.

TensorFlow 2.15.0 MediaPipe Landmarks OpenCV Stream Keras Serialization Python 3.9+

🔑 Pipeline Architecture:

  • Frame Ingestion: Deployed OpenCV to handle multi-threaded webcam video stream frames at low latency.
  • Feature Extraction: Utilized MediaPipe to map and extract 21 precise 3D hand landmark coordinates, transforming raw pixel matrices into isolated structural geometries.
  • Deep Learning Architecture: Designed and trained a neural network in TensorFlow to classify geometric landmark coordinates into alphanumeric characters.
  • Strict Environment Serialization: Deployed custom model checkpoints compiled explicitly under TensorFlow 2.15.0 using native `.keras` formatting to prevent layer configuration friction during cross-platform inference.
